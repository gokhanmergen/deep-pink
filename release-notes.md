# 0.18.0

- Sync tracks which device last replied in each thread and can show that device in the sidebar.
- Choose a desktop or laptop icon and a color for each sync device.
- Update checks now recognize prereleases as older than the matching stable release.
- Backspace now focuses the prompt and deletes on the first press.
- Threads get an unread dot when a reply finishes while they are out of view.
- Image-only messages show the image immediately without an empty text bubble.
